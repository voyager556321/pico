# UI/UX brief — простими словами

Для дизайнера. Технічні деталі — у `HANDOFF.md`.

**Продукт:** **Pico** — *A payment layer for on-demand AI*

---

## Що ми робимо (1 хвилина)

Ми **не** робимо новий гаманець типу Phantom.

Ми робимо **передплачену картку для AI-дій** (Pico):
1. Кидаєш трохи грошей (бюджет)
2. Кожна дія коштує копійки ($0.01–$0.05)
3. Завжди видно, скільки лишилось
4. Можна закрити рахунок

Без підписки $20/міс. Платиш лише коли користуєшся.

**Одне речення:**  
«Pico — payment layer для on-demand AI: кидаєш бюджет і платиш по копійках за кожну дію.»

---

## Головне правило дизайну

Юзер **ніколи не повинен боятись сюрпризу по грошах**.

Завжди показуй:
- ціну **перед** дією
- залишок **після** дії
- що робити, коли гроші закінчились (disabled / top up)

---

## Екрани (намалювати це)

### 1. Старт / Landing
- Назва продукту
- 1 речення: навіщо це
- Кнопка **Connect wallet**

### 2. Бюджет
- Скільки зараз на рахунку
- Швидкі суми: **$1 / $2 / $5**
- Кнопка поповнити
- Коротка підказка: «Це ліміт витрат на AI, не весь гаманець»

### 3. Інструменти (головний екран)
Дві картки:

| | Explain Tx | Token Check |
|---|------------|-------------|
| Що робить | Пояснює транзакцію простими словами | Перевіряє токен на ризики |
| Ціна | $0.01 | $0.05 |
| CTA | Run | Run |

Поле вводу (signature / address) + кнопка.

Опційно: кнопка **«Agent demo: 10 викликів»** (для пітчу).

### 4. Результат
- Відповідь AI (читабельний блок)
- Банер: **Списано $0.05 · Лишилось $4.95**
- Кнопки: ще раз / на головну / історія

### 5. Історія (чек)
Список рядків:
`Token Check · $0.05 · 14:32 · залишок $4.95`

Як банківська виписка — просто і прозоро.

### 6. Закрити / Settle
- Підсумок: витрачено X, повернуто/залишок Y
- Статус «успішно»
- Посилання «подивитись у explorer» (для жюрі)

---

## Стани, які треба спроєктувати

- Порожній бюджет (ще не депозитив)
- Мало грошей (не вистачає на tool)
- Завантаження (йде AI-запит)
- Помилка (недостатньо коштів / мережа)
- Успіх

---

## Тон і вигляд

- Спокійно, зрозуміло, «фінтех-довірливо»
- Не крипто-казино, не «AI purple glow»
- Великі цифри балансу і ціни
- Мало тексту, багато ясності

---
