PICO02 / Problem

Agents need to spend.
Humans won’t hand over the wallet.

  • Subscriptions waste money on idle capacity — then cap you mid-run.
  • Builders juggle 6–8 prepaid API balances; one dies at 2am → pipeline fails.
  • Agents can’t do Stripe / KYC. Full wallet access is a non-starter.

PICO05 / Why we built it

Payment UX for AI is still subscriptions & API keys.

  • Why now: agent economy + Solana micropayments (x402 narrative). $0.01–$0.05 fees finally work.
  • Why us: fast loop — custom escrow → live meter → useful Solana tools.
  • Why Solana: only cheap rails make pay-per-call viable; Anchor program proves it’s not a Stripe wrapper.
